# 第一跳可观测性（四期）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收掉三期终审留下的 8 项优先项——桌面端把入口主机名并进窗口、断链后停采样、心跳循环可测、累加器换代带世代号；服务端运营商维度改 ASN 做键、告警去重可过期、调度线程池加到 2、反查缓存可配。

**Architecture:** 桌面端把与 Tauri 外壳无关的心跳/采样逻辑从 `lib.rs` 搬到新模块 `link/report.rs`，循环体拆成「纯逻辑决策」+「I/O 接线」两层；累加器自带入口主机名与世代号，窗口与入口不再靠两处对齐。服务端三张表的 `isp` 列换成 ASN，新增 `asn_org` 只做展示名，归档/告警/查询的分组键统一为 `(failure_domain, asn)`；去重状态按 `alerted_at + ttl` 过期。**跨两个仓库，两条线互不依赖，可并行。**

**Tech Stack:** 桌面端 Tauri 2 / Rust / tokio；服务端 Spring Boot 3 / MyBatis-Plus / Flyway / MySQL 8.4 / Testcontainers；管理端 Vue 3 + TS + Vitest。

**Spec:** `docs/superpowers/specs/2026-09-21-第一跳可观测性四期-design.md`（三期背景见 `2026-09-17-第一跳稳定性与可观测性-design.md` §8）

- 心跳上报契约 `LinkHeartbeatRequest`（`POST /api/link/heartbeat`）**本期不改**：字段名、可空性、`null` 序列化逐字不变。

`sampler.rs` 关键改动：

```rust
/// 一个故障域在本次建链下的静态信息：名字 + 该组首节点的入口域名（解析入口 IP 用）。
/// 入口域名随窗口一起走，上报时不再回头读 `state.link`——建链换代与在途心跳之间没有可乘之隙。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DomainSpec {
    pub failure_domain: String,
    pub entry_host: Option<String>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum RecordOutcome {
    /// 调用方拿的是换代前的世代号：本轮快照来自旧内核，整轮丢弃、不记、不唤醒
    STALE,
    RECORDED { jumped: bool },
}

pub struct WindowAccumulator {
    windows: Vec<DomainWindow>,
    last_now: Vec<Option<String>>,
    last_round_had_alive: Vec<Option<bool>>,
    window_start: SystemTime,
    /// 世代号：每次换代（重连、登出）+1。采样循环一轮跨几十秒，中途换代时它读到的
    /// 是旧内核的快照，靠这个号在 `record_for` 里挡掉
    generation: u64,
}
```

- `record_for(generation, statuses)`：`if generation != self.generation { return RecordOutcome::STALE; }` 然后是原 `record` 的逻辑，返回 `RECORDED { jumped }`。
- 删除 `record` 与 `drain`。
