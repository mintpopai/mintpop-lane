# 管理端「线路」菜单重构 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理端侧栏新增「线路」分组（机场订阅 / 落地节点），机场订阅页按机场分 tab 展示订阅，节点下沉到订阅详情页；独立的「机场」菜单并入机场订阅页；管理端界面文案去掉「第一跳 / 第二跳」。

**Architecture:** 纯前端改造（`apps/admin`），不改服务端，也不新增接口。原 `NodesView.vue`（533 行）和 `AirportsView.vue` 拆成三个页面：`AirportSubscriptionsView`、`SubscriptionDetailView`、`LandNodesView`。订阅额度的展示抽成工具函数加一个小组件，两页共用。路由上，订阅详情挂成机场订阅的子路由，借 vue-router 对空路径子路由的激活规则，让侧栏在详情页也高亮「机场订阅」。

**Tech Stack:** Vue 3（`<script setup>` + TS）、vue-router 4、Pinia、Vitest + @vue/test-utils；命令统一走 mise。

**Spec:** `docs/superpowers/specs/2026-09-29-管理端线路菜单重构-design.md`

## Global Constraints

- **不改后端**：只用现有的 `adminApi()` 方法（`listAirports`、`listAirportSubscriptions`、`listNodes`、`deleteAirport`、`deleteAirportSubscription`、`deleteNode`）。
- **新路由**：`/lines/airports`（`AIRPORT_SUBSCRIPTIONS`）、`/lines/airports/subscriptions/:id`（`SUBSCRIPTION_DETAIL`）、`/lines/land-nodes`（`LAND_NODES`）。`/nodes`、`/airports` 重定向到 `/lines/airports`。删除 `NODES`、`AIRPORTS` 路由名。
- **侧栏**：分组标题「线路」不可点击、始终展开，子菜单为「机场订阅」「落地节点」。删除「机场」菜单。
- **文案改名只动管理端界面文案**：代码标识符（`FRONT`/`LAND`）、代码注释、服务端返回的错误文案（如「没有可分配的第一跳订阅」）都不改。
- **流量额度**：拿不到时写「未提供」，不显示 0%；`totalBytes <= 0` 视同拿不到；百分比封顶 100。
- **切机场 tab**：用 `router.replace` 改 `?airport=`，不往历史栈里压记录。
- **注释用中文，标识符用英文**；测试描述用中文写在 `it()` 里。
- **门禁命令**：`mise run lint-admin`（eslint + prettier + vue-tsc）、`mise run test-admin`、`mise run build-admin`。
- **视觉检查**：用 Claude in Chrome 看真实页面。管理端 dev server 用 `mise run run-admin`，端口 6201。

## Review Focus

2. **订阅名链接和整行点击同时触发**，导致连续两次导航 → 点链接只导航一次。→ 由 Task 4 的「点订阅名不重复 push」用例覆盖。

`apps/admin/src/utils/subscriptionQuota.ts`：
```ts
import type { AirportSubscriptionResponse } from "../api/types";

/**
 * 订阅的流量用量百分比。null 表示「该机场没提供额度头」，与 0% 是两回事——
 * 不能把「没数据」显示成「用了 0%」。total 缺失或非正也一并视为没有数据，
 * 避免除出 NaN / Infinity。封顶 100：机场统计口径可能比订阅端晚一拍，用量偶尔会略超总量。
 */
export function quotaPercent(
  sub: Pick<AirportSubscriptionResponse, "usedBytes" | "totalBytes">,
): number | null {
  if (sub.usedBytes === null || sub.totalBytes === null || sub.totalBytes <= 0) {
    return null;
  }
  return Math.min(100, Math.round((sub.usedBytes / sub.totalBytes) * 100));
}
```
